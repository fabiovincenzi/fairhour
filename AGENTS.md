# Instructions for AI coding agents

This repository is developed with AI assistance. The authoritative guide for any agent
(Claude Code, Codex, Copilot, Cursor, …) is [CLAUDE.md](CLAUDE.md): repo map, commands,
conventions, the definition of done and the hard rules. Tax packages have extra rules in
[packages/tax-core/CLAUDE.md](packages/tax-core/CLAUDE.md).

Tooling versions in this repo may be newer than your training data. Before changing
configuration, read the docs bundled with the installed package (for example
`node_modules/turbo/docs/`, `node_modules/next/dist/docs/` when present) and the package's
type definitions, and prefer them over memory.
